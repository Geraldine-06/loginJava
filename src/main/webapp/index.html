SIGA centraliza el acceso de administradores, coordinadores, directivos, secretarías y docentes en un solo portal, con contraseñas cifradas, sesiones con JWT y recuperación de cuenta por correo electrónico.

Iniciar Sesión

¿Qué incluye este módulo?

El mismo frontend funciona con tres backends: Python Flask, Java (Maven + Tomcat) y Node.js.

🔐

Contraseñas con hash

Las claves se guardan cifradas con BCrypt; nunca en texto plano.

🎫

Sesión con JWT

Al ingresar recibes un token firmado que identifica tu sesión.

✉️

Recuperación por correo

Enlace con token de un solo uso que vence en 15 minutos.

🧩

Arquitectura MVC

Modelo, Vista y Controlador separados para un código ordenado.
